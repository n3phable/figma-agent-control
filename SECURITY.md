# Security

Report a vulnerability privately to **n3phable@163.com**. Include the affected
version, a minimal reproduction and the observed impact. Sanitize pairing tokens,
personal paths, private document keys and design content before sharing evidence.
Security fixes target the latest tagged release.

The bridge listens on `127.0.0.1` and authenticates CLI and plugin requests
separately. Trusted run scripts have full Plugin API access to the current file.
The binding defines valid task targets, and the selected target defines the
subtree covered by snapshots, change sets and visual checks.

FAC records evidence and establishes Undo boundaries before writes. When a
write result is unknown, stop the previous plugin, inspect the original target
and resolve that job before starting another write. Use the original job ID to
retrieve persisted results and preserve the evidence needed for review.

The [protocol](docs/protocol.md) defines the request, evidence and recovery rules.
